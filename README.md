# Talismans

Paper 1.21.4 plugin that adds two enchanted Totem of Undying-based talismans.

## Talismans

### Талисман Жизненной силы
- +4 hearts (+8 max health)
- -3 armor

### Талисман Воина
- +3 attack damage
- +2 armor toughness
- +2 hearts (+4 max health)

The bonuses are active while the talisman is held in either hand.

## Commands

`/talisman give <player> vigor`

`/talisman give <player> war`

Permission: `talismans.admin`

## Build

Requires Java 21.

`gradle build`

The built plugin is in `build/libs/Talismans-1.0.0.jar`.
